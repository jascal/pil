# Why the uniform substitution certificate fails: hull ceiling vs alignment — pre-registration

**Status: written 2026-10-04, committed and pushed before any code for this study existed.**

**Context.**
- jascal/pil#135 / #136: the T5(a) **uniform** certificate (`margin > 2δ`, `δ = max_v |⟨u − û, U_v⟩|` over the
  full vocabulary) covers ≤ 0.006 of test contexts for every compressed substitute of GPT-2 small's decode input.
  The exact **pairwise** certificate covers exactly the contexts where the substitute agrees with the host.
- jascal/i-orca#29 (`PIC_Binding.thy`, kernel-checked): `certificate_hull_ceiling` / `substitution_hull_ceiling`.
  For a bias-free decode, a certificate that needs every margin `> m` can fire only if
  `m < ‖u‖ · h(t)`, where `h(t) = infdist(U_t, conv{U_v : v ≠ t})` is the hull distance of the decision token.
  This ceiling is set by the frame `U` and the residual norm, not by the substitute.

**The question.** When the uniform certificate refuses a context, which of two things is the cause?
- **CEILING.** `2δ ≥ ‖u‖·h(t)`. No residual of norm `‖u‖`, pointing in any direction, could be certified with this
  substitute error. Only a smaller `δ` (a better fit) helps; widening the host's margin by realigning `u` cannot.
- **ALIGNMENT.** `2δ < ‖u‖·h(t)`, yet `m ≤ 2δ`. The geometry would allow certification, but the host's residual
  sits below the hull-optimal margin. Margin widening (PROPOSAL T6, clean-up) has room here.

This study measures that split. It does not try to raise coverage.

## 1. Model, site, tasks, data

- GPT-2 small, frozen, float32 forward, float64 analysis. The site is the decode input `u = ln_f(h_L)` at the
  final position, and logits are `U u`: tied, no bias, so the bias-free theorem applies exactly. `t` is GPT-2's
  own argmax.
- **Tasks and families as in `certified_substitutes_prereg.md` (#136):** LIST and SVO; `tpr` and `paircode` at
  both budgets (B₈, B₃₂), each under both objectives (`mse`, `cert`). Generated by the #136 code
  (`build_rows`, `build`, `train`).
- **Fresh seeds:** stimulus **31**, split **32**, fit seed **0** only. 12,000 contexts per task; split 60 / 10 / 30.
  Test contexts with an unseen (filler, role) pair are dropped and counted, as in #136.
- **Positive control:** the rank-k PCA projection of `u` fitted on train, with `k` = 32. (#134's rank-matched PCA
  was uniformly certified on 94%, so the control should be mostly *certified*, not refused.)
- So each task has 8 substitute cells plus 1 control.

## 2. Quantities (test split)

Per context `x`: `t`, the margin `m = L(t) − max_{v≠t} L(v)`, `δ = max_v |⟨u − û, U_v⟩|` over all 50,257 tokens,
`‖u‖`, and the uniform verdict from the Soufflé checker in `substitution_certificate.py` (unchanged).

**Hull distance `h(t)`**, per distinct decision token `t`, against **all** other 50,256 tokens:
- Solve `min_λ ½‖U_t − Σ_v λ_v U_v‖²` over the simplex, using Frank–Wolfe with away steps.
- Report a certified **bracket** `[h_lo, h_hi]`:
  - `h_hi` = the distance to the current hull point (feasible, so an upper bound);
  - `h_lo = sqrt(max(0, 2(f − g)))`, where `f` is the current objective and `g` the Frank–Wolfe duality gap
    (`f* ≥ f − g`).
- Stop when `(h_hi − h_lo) ≤ 10⁻³ · h_hi`, or at **20,000 iterations**. The cap is fixed now.

## 3. Classification (uniform-refused contexts only)

- **CEILING** if `2δ ≥ ‖u‖·h_hi`. Since `h ≤ h_hi`, this is certain.
- **ALIGNMENT** if `2δ < ‖u‖·h_lo`. Since `h ≥ h_lo`, this is certain.
- **UNDECIDED** otherwise (the bracket straddles `2δ / ‖u‖`).
- A relative slack of 10⁻⁹ on each comparison absorbs float64 rounding; a comparison inside the slack is
  UNDECIDED.

**Soundness check (aborts the run).** The theorem gives `m ≤ ‖u‖·h(t)` for every context. Every context must
satisfy `m ≤ ‖u‖·h_hi·(1 + 10⁻⁹)`. A violation means a solver or pipeline bug; the run stops and nothing is
reported as a result.

**Descriptive, per cell:**
- the shrink factor `ρ = 2δ / (‖u‖·h)` on CEILING contexts, using `h_hi` (so `ρ` is a lower bound on the needed
  reduction): median and quartiles;
- the alignment efficiency `m / (‖u‖·h_hi)` on all contexts (≤ 1 by the theorem): median.

## 4. Decision rules (fixed now)

- **Solver adequacy.** If more than 5% of a cell's refused contexts are UNDECIDED, that cell is reported as
  **solver-limited** and not classified. There is no re-run with a larger cap.
- **Per cell** (one task × family × budget × objective), over its refused contexts that are not UNDECIDED:
  - **CEILING-BOUND** if ≥ 80% are CEILING;
  - **ALIGNMENT-BOUND** if ≥ 80% are ALIGNMENT;
  - **MIXED** otherwise.
- **Headline:** the majority label over the 16 substitute cells (2 tasks × 8). If no label has a majority of the
  classified cells, the headline is **MIXED**.
- **Control check:** the PCA control must be uniformly certified on ≥ 50% of test contexts on both tasks. If not,
  the pipeline differs from #134's and is investigated before any substitute cell is read. This is reported, never
  silently fixed.

**What each headline means for the program (stated now):**
- **CEILING-BOUND:** threshold certificates are capped by the fit error relative to GPT-2's hull geometry.
  Margin widening (T6) is not the lever; better fits or a non-threshold certificate are.
- **ALIGNMENT-BOUND:** the geometry permits certification at these errors and GPT-2's residuals waste it. T6-style
  clean-up is the next experiment.
- **MIXED:** both are reported per cell; neither direction is preferred on this evidence.

## 5. Not claimed

- `h(t)` is a property of GPT-2 small's tied unembedding. Nothing is claimed for other models.
- The classification concerns **threshold** certificates (uniform; the same ceiling applies to the norm form and
  the hybrid tail). The exact pairwise certificate is an iff and has no ceiling.
- Coverage is `empirical`, per context, on this finite test set. Nothing extends to unseen contexts: the T5(b)
  domain certificate (i-orca#29) needs an error bound on all of the domain, and that bound stays `open`.
- An ALIGNMENT verdict says only that a better-aligned residual *of the same norm* would be certifiable. It does
  not say clean-up can find one.
